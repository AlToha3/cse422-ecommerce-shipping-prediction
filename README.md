# E-Commerce Shipping Prediction

A machine learning project developed for BRAC University (CSE422: Artificial Intelligence) to predict e-commerce shipment delivery status using KNN, Decision Tree, Logistic Regression, Neural Networks, and K-Means Clustering.

## Dataset
- E-Commerce Shipping Dataset
- 10,999 shipment records
- Binary Classification Problem

## Models Used
- K-Nearest Neighbors (KNN)
- Decision Tree
- Logistic Regression
- Neural Network
- K-Means Clustering

## Results

| Model | Accuracy |
|---------|---------|
| Decision Tree | 67.82% |
| Neural Network | 65.77% |
| Logistic Regression | 63.77% |
| KNN | 62.73% |
